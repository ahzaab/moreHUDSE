## New features

- Added localized interior location status to door rollover text, showing whether the destination is unvisited, visited, visited but not cleared, or cleared.
- Added MCM options to enable location status, limit it to dungeons, hide unvisited destinations, and show it only at exterior-to-interior entrances. By default, status is enabled for visited dungeon entrances from outside.
- Persisted location-status options through plugin globals, with support for FISS and JSON configuration presets.
- Updated Completionist integration to API V20 and added icons for displayable, displayed, and occupied museum displays alongside needed and collected items.

## Fixes and packaging

- Suppressed rollover icons when Skyrim hides the vanilla rollover text, including during book reading.
- Refreshed rollover icons when a HUD mode ends so they return without moving the crosshair.
- Included the GPL license at the root of both ESP and ESL Nexus packages.

GitHub release page contains the source tag only; Nexus packages are distributed separately.
