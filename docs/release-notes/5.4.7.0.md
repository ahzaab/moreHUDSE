## Fixes and hardening

- Corrected the book-read icon query so temporary HUD visibility changes do not change the book's read state. BookMenu/BookMode suppression remains active.
- Restored the main HUD movie byte-for-byte to the compatible 5.4.5.0 version. The 5.4.6.0 package accidentally included a generated test movie with a call to an unregistered native function. No authored AS2/FLA changes are required, preserving the existing interface for HUD reskins.
- Moved target-related inventory counts, equipment comparisons, localized skill names, Completionist API queries, and registered form-list membership checks into the authorized crosshair hooks. UI callbacks consume owning, pointer-free snapshots.
- Made target derivation local to each hook invocation, with locked snapshot copying and ordered publication to prevent an older concurrent invocation from replacing newer data. Transient target pointers are cleared before returning from the hook.
- Kept enemy data collection inside its owning enemy-reference lookup hook, including soul-name and player-level capture, and hardened null and relocation handling.
- Added a main HUD movie hash check to the release pipeline to prevent reuse of unexpected generated SWFs.

## Completionist diagnostic option

To compare behavior with moreHUD's Completionist API integration disabled, add the following to `Data/SKSE/Plugins/AHZmoreHUDPlugin.ini` and restart Skyrim:

```ini
[Compatibility]
EnableCompletionistAPI=0
```

Completionist remains installed. The integration is enabled by default; set the option to `1` and restart to restore it.

## Validation

The SE/AE/VR native build, snapshot boundary checks, book-read callback regression test, and ESP/ESL archive checks passed. In-game confirmation of the reported flashing and Scaleform crashes is still pending; this release does not claim a proven fix for the crash cause.
